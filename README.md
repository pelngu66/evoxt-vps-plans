## 같은 요금제인데 트래픽이 2~5배 갈리는 이유

Evoxt 네트워크는 스탠더드, 프리미엄, 프리미엄 플러스 세 등급으로 나뉜다. 요금제 이름과 가격은 거의 같지만 월 트래픽 한도가 다르다.

- **스탠더드**: 미국, 영국, 캐나다, 독일, 폴란드, 암스테르담, 도쿄, 말레이시아, 호주 등. 트래픽이 가장 넉넉하다.
- **프리미엄**: 홍콩, 오사카. 트래픽이 스탠더드보다 적다.
- **프리미엄 플러스**: 말레이시아 프리미엄 전용. 트래픽이 가장 적다.

숫자로 보면 차이가 분명하다. VM-0.5는 스탠더드 500GB, 프리미엄 250GB, 프리미엄 플러스 150GB다. VM-16은 스탠더드 10TB, 프리미엄 5TB, 프리미엄 플러스 4TB다. 같은 이름의 요금제를 고르고도 등급에 따라 쓸 수 있는 트래픽이 2~5배 벌어진다.

가격이 달라지는 경우는 하나뿐이다. VM-0.5의 프리미엄 플러스가 $2.99가 아니라 $3.49/월이다. 나머지 요금제는 등급이 달라도 가격이 같다.

판단은 여기서 갈린다. 도쿄나 미국처럼 트래픽이 넉넉한 스탠더드를 고르면 같은 돈으로 더 많은 트래픽을 가져간다. 오사카나 홍콩의 회선 품질이 필요하면 트래픽을 포기하고 프리미엄을 골라야 한다. 트래픽이 예상보다 빨리 차는 사이트라면 처음부터 스탠더드가 답이다.

## 용도별로 어느 요금제를 고를까

**리눅스 학습, 가벼운 봇 → VM-0.5 ($2.99)**
512MB RAM으로도 Debian이나 Alpine에 sshd, cron, 소형 봇 하나를 돌리는 데는 여유가 있다. CPU가 6.0GHz까지 올라가서 컴파일이나 스크립트 실행은 같은 가격대의 국내 저가 VPS보다 빠르다.

**Docker 실험, API 서버 → VM-1 ($5.99)**
2GB RAM에 20GB 스토리지, 1TB 트래픽이다. Docker Compose로 컨테이너 몇 개를 띄우고 외부 API와 통신하는 정도라면 무리 없이 돌아간다. 대부분의 개인 프로젝트가 여기서 끝난다.

**WordPress, 중규모 사이트, 스트리밍 확인 → VM-2 ($11.99)**
4GB RAM에 30GB, 2TB 트래픽이다. Nginx + PHP-FPM + MySQL을 올려 월 수만 PV를 처리하는 용도에 맞는다. 도쿄 리전에서 스트리밍 접속을 확인하려면 브라우저 자동화가 안정적으로 돌 정도의 RAM이 필요한데, VM-1보다 VM-2가 낫다.

**팀 개발, CI 빌드 → VM-4 ($23.99) 이상**
4코어 8GB에 60GB다. 병렬 빌드나 여러 명이 쓰는 개발 샌드박스를 한 대에 올릴 수 있다.

**무거운 워크로드 → VM-8 ($47.99) 이상**
8코어 16GB면 PostgreSQL 본선에 캐시 계층, 배치 작업까지 한 서버에서 감당한다. 여기부터는 트래픽도 6TB 이상 붙어서 대역폭 걱정이 줄어든다.

## 요금제를 올릴까, 자원만 추가할까

Evoxt는 요금제를 갈아타지 않고 필요한 자원만 더할 수 있다.

- CPU 1코어: $3/월
- RAM 1GB: $2/월
- 추가 IP: $3/월
- 트래픽: 스탠더드 $3/TB, 프리미엄 $12/TB, 프리미엄 플러스 $24/TB

여기서 계산이 갈린다. VM-1($5.99)에서 VM-2($11.99)로 가면 월 $6를 더 내고 RAM 2GB, 코어 1개, 스토리지 10GB, 트래픽 1TB를 얻는다. 같은 자원을 하나씩 추가하면 RAM 2GB에 $4, 코어 1개에 $3로 합계 $7이다. 이 경우는 요금제를 올리는 쪽이 $1 싸다.

반대로 RAM만 1GB 모자란 상황이라면 추가 비용 $2로 끝난다. 상위 요금제로 가면 $6를 더 내야 하니 자원 추가가 훨씬 저렴하다. 기준은 이렇게 잡으면 된다. 필요한 자원이 한두 개면 추가, 여러 개가 동시에 모자라면 업그레이드다.

트래픽 추가 단가는 등급마다 4배, 8배씩 벌어진다. 프리미엄에서 트래픽을 더 사면 스탠더드의 4배, 프리미엄 플러스는 8배다. 대용량 트래픽이 예상된다면 처음부터 스탠더드를 고르는 편이 낫다.

장기 결제도 가능하다. 최대 3년까지 선불로 낼 수 있고 할인이 붙는다. 구체적인 할인율은 결제 단계에서 확인해야 한다. 계정에 크레딧을 충전해 두고 다음 청구서에 자동 차감되게 하는 방식도 있다. 👉 [자원 추가 단가와 VM-1 요금 확인하기](https://bit.ly/EvoXt)
